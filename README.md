## Datadog Monitoring for SAP HANA on AWS

**Problem:** Alert fatigue from backup operations causing on-call teams to ignore monitoring alerts.

**Solution:** Implemented Datadog's anomaly detection to distinguish expected backup behavior from actual problems.

**Results:** 
- 95% reduction in false positive alerts
- Improved on-call response
- Caught real issues masked by threshold-based alerts

**Tech:** Datadog, AWS, SAP HANA, Terraform
